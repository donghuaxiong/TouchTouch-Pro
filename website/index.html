核心功能

手不离触控板，一切尽在掌控

TouchTouch Pro 将四种常用系统调节整合进触控板边缘，单手即可完成所有操作。

🎯

修饰键分层控制

Option 层控制亮度和音量，Control 层控制键盘背光和麦克风。两层独立、互不干扰，上手即用。

💎

精美 HUD 浮层

每次调节弹出玻璃质感浮层，四种图标精确对应控制目标，亮/暗两种主题随心切换。

⚡

触觉反馈

每次触发都伴随震动确认，1~3 档强度可调，让你在触控板上就能感知每一次变化。

🔧

全参数可调

边缘宽度、滑动阈值、调节步长、防抖时间、方向反转——每个细节都可由你定制。

使用方式

两个修饰键，四个控制目标

按住修饰键不放，手指在触控板边缘上下滑动即可调节。

01

按住 Option 键

在触控板左边缘滑动 → 调节屏幕亮度
在触控板右边缘滑动 → 调节系统音量

⌥ Option ← 左边缘 右边缘 →
02

按住 Control 键

在触控板左边缘滑动 → 调节键盘背光
在触控板右边缘滑动 → 调节麦克风音量

⌃ Control ← 左边缘 右边缘 →
